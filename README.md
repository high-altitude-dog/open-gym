# Open Gym

The gym's check-in code as a home-screen web app. Install it from **https://high-altitude-dog.github.io/open-gym/** (Android: Chrome; iPhone: Safari), open it from the home screen, make your key, and ask the front desk to link your phone.

- Your key is made on your phone and never leaves it. The app works with no data once installed.
- Every 10 seconds it shows a new QR code that only your phone can make; the gym's reader checks it.
- Plain HTML and JavaScript, no build step and no third-party scripts. Libraries in `vendor/` (see `vendor/README.md`).
